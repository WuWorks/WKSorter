# WKSorter 学习参考 · Code references

这里分享 WKSorter 的少量 C# 辅助代码，供非商业学习。使用 WKSorter 请从 [Releases](https://github.com/WuWorks/WKSorter/releases/latest) 下载安装包。

| 文件 | 用途 |
| --- | --- |
| [WindowsThemePreference.cs](WindowsThemePreference.cs) | 读取 Windows 深浅主题偏好，订阅系统外观变化，并释放事件订阅 |
| [ScheduleFrequency.cs](ScheduleFrequency.cs) | 定义手动、每日、每周、每月及单次运行的频率枚举 |

这里只提供独立的代码参考。完整应用的安装包由 Releases 提供。适用条款见 [非商业使用许可](../LICENSE.txt)。
